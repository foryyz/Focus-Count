# 更新记录

本文件说明已实现的行为变化。Mac 与 iPhone 独立版本；数据协议仍为 JSON v5。2026-09-30 整理当前 Git 发布基线：Mac 1.19.7（53）、iPhone 1.5.6（13）。下列较早小版本按开发记录补录，不代表每版均有独立 Git 标签。

## Mac 1.20.0（55） · 2026-10-02

- 所有 Mac 应用设置集中到数据目录内的 `settings.plist`，包括模式参数、声音选择、颜色、emoji、分类、目标显示、同步开关及分析窗口尺寸。
- 启动不再从旧项目或系统偏好自动恢复数据；目录缺失时空记录、默认参数启动。首次升级无设置文件时使用默认设置，已有记录、目标和音频保留。
- 清理旧系统偏好中的应用设置键；坏设置文件保留并报错，禁止自动覆盖。
- iPhone 保持原有本机存储方式，通过共享接口继续兼容导入导出。
- 验证：Core 38 项、Mac 78 项、iPhone 模拟器 40 项测试通过；新增目录清空与默认值、坏文件保护、旧偏好清理及文件设置同步回归。

## Mac 1.19.8（54） · 2026-10-02

- 修复清空主数据库后旧目标倒计时自动恢复的问题。
- 正式应用以数据库 `goal` 为唯一目标内容来源，清除 UserDefaults 的旧副本并停止重复写入；隐藏与显示格式偏好保留。
- 已被旧版恢复并写回数据库的目标属于现有数据，升级不自动删除，可在目标设置中删除。
- Mac 76 项测试通过，共享代码的 iPhone 编译通过。本次仅更新 Mac 分发版本。

## Mac 1.19.7

- 专注分析扇形图按实际文字尺寸和扇区边界放置名称与占比，支持换行、位置和字号调整，不再用固定占比决定是否外置。
- 环形图同样优先在分区内显示文字，避开中心统计信息。
- 外侧引线与标签沿用活动或分类颜色，并根据浅深色背景调整可读性。
- 仅在需要的一侧预留外侧标签空间，使图表充分利用窗口。
- 验证：Mac 74 项测试通过，覆盖扇区边界、圆环中心避让和两种宽度的浅深色渲染；iPhone 共享文件编译通过。Mac 安装包已构建并校验。

## Mac 1.19.6 / iPhone 1.5.6

- 频率总览聚合达到 4 次即在图标下方显示数字。
- Mac 时间分布沿用相同数字样式，缩小 2 次聚合图标，使其与 3 次更易区分。

## Mac 1.19.5 / iPhone 1.5.5

- 提示音同步、模式数值参数同步移入设置的“同步设置”，默认关闭并记住本机选择。
- 导入预览更简洁；计时状态仍在预览中单独选择，默认关闭。

## Mac 1.19.4 / iPhone 1.5.4

- 新增删除全部历史版本，清理本机导入备份和记录旧版本，保留当前记录及计时状态。
- 删除旧版本产生可同步的删除标记，避免旧文件导入后恢复已清除的历史；其他设备本机备份需单独清理。

## Mac 1.19.3 / iPhone 1.5.3

- 支持删除单个导入备份和记录旧版本。
- 导出文件内写入导出时间与设备来源，并提供可读时间字段；预览不再以文件修改时间推断导出时间。内嵌字段不属于防篡改签名。

## Mac 1.19.2 / iPhone 1.5.2

- 历史页面列出导入备份，支持查看和恢复合并。
- 导入预览简练展示同步规则、实际变化及文件来源；声音与数值参数可选择同步（后续 1.19.5 / 1.5.5 移到设置）。
