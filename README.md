# FocusCount

专注计时与时间标记工具。提供 macOS 与 iPhone 原生 SwiftUI 客户端；Windows 11 客户端尚未实现。iPhone 开发与运行方式见 [apps/ios/README.md](apps/ios/README.md)。

## 当前版本

- **macOS 1.29.0（72）**：课程模式、独立音量、导入卡死修复、返回主页暂停/恢复，以及珠光流彩主题与阶段预览。
- **iPhone 1.14.0（29）**：同步课程、声音、返回主页与主题功能；支持课间通知和持续庆祝。
- 两端使用 JSON v5 手动导出、导入并合并记录和目标日期；同时交换分类、颜色、emoji 和目标显示设置；提示音与模式参数是否导出在设置中选择，默认关闭；目标日期默认导出。选择记住本机状态，导入按文件内容合并；计时接续默认关闭。

## 新增功能

设置 → 主题可切换“经典”和“珠光流彩”，并预览 0–10 小时。主题逐小时升级丝绸文字、背景与星星；5 小时点亮输入框灯带，8 小时起使用无绿色的流动灯带，9 小时显示深粉/紫/玫瑰红时间与成就倒计时，10 小时显示 🎉YOU MADE IT. 并持续庆祝。9–10 小时有精细椭圆光轨。开始专注始终保持原 RGB 粉色渐变。完整阶段、统计口径与兼容规则见 [主题说明](docs/theme.md)。

“开始专注”采用鲜亮的旋转渐变、柔光与扫光，Mac 悬停时轻微放大并增强光晕；动画遵循减少动态效果设置。

专注中点击左上角“返回”可查看主页并暂停当前计时与模式提醒。主页隐藏活动输入框，按钮变为 RGB 流动的“恢复专注”；点击后返回原计时页面并继续原计时与模式提醒。暂停、休息与取消状态均沿用原轮次，不能在此状态下创建第二个计时。

三种模式分别保存音量，切换模式不会改变其他模式的音量；旧设置以原音量初始化三项。恢复默认只重置所选模式。

- **课程模式**：模式菜单中选择“课程模式”，在“调整模式参数与声音”设置一节课和课间休息时长，默认分别为 60 分钟和 10 分钟。上课、下课可分别选择内置或自定义提示音并试听；课间结束自动开始下一节课，课间不计入专注时长。手动暂停冻结当前阶段，也可跳过课间。重新开始课程后使用新参数。
- **普通专注提示音**：模式设置中选择“普通专注”，分别设置开始／继续与暂停声音，并调整音量。
- Mac 与 iPhone 均支持。Mac 休眠或重启后暂停课程；iPhone 后台继续计时，通过通知播放上下课提醒，每次安排未来 64 次阶段切换（约 32 节课），打开应用后补齐。后台声音受系统通知权限、音量、静音和专注模式影响。
- 参数、提示音与目标日期的导出内容由设置中的独立开关决定；关闭目标日期同时排除目标显示设置。导入按文件实际内容合并，缺少的项目保留本机值。课程计时可通过“同步计时状态”接续。Mac 安装包见下文；iPhone 通过 Xcode 签名安装。

## 安装与更新

### Mac

当前本地打包产物为 [FocusCount-1.29.0-macOS.zip](dist/macos/FocusCount-1.29.0-macOS.zip)，适用于 **Apple 芯片 Mac、macOS 13 及以上**。

1. 退出正在运行的 FocusCount。
2. 解压 ZIP，将 `FocusCount.app` 放入“应用程序”文件夹；更新时替换旧应用。
3. 打开新版应用，原有数据仍保存在当前用户的应用数据目录。

压缩包只包含应用，不包含个人记录。接收方无需项目源码或 Xcode。该应用采用本地 ad-hoc 签名，未进行 Apple 公证；系统可能要求确认打开。当前压缩包不适用于 Intel Mac。

`dist/` 不进入 Git，以上链接指向本地构建产物；新克隆项目请按下文构建，或向分发者获取压缩包。

### iPhone

打开 [FocusCount.xcodeproj](apps/ios/FocusCount.xcodeproj)，连接 iPhone，选择原 Apple Team 和设备，按 **Command-R** 编译并覆盖安装。更新时保持相同 Bundle Identifier，不要先卸载旧应用，以保留数据。Mac ZIP 和 iOS 模拟器产物不能安装到 iPhone；详细步骤见 [iPhone 说明](apps/ios/README.md)。

## macOS 构建与运行

要求 macOS 13+、Swift 5.9+。从项目根目录运行：

```sh
bash scripts/build-app.sh
open dist/macos/FocusCount.app
```

脚本生成本机架构的应用并进行 ad-hoc 签名，未进行 Apple 公证。构建完成后会自动生成并校验 ZIP，将旧版压缩包移入 `dist/macos/history/`，当前目录只保留最新版 ZIP。打包步骤需要 Python 3。也可开发运行：`swift run --package-path apps/macos`。

编译并打包当前版本（在项目根目录运行）：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer bash scripts/build-app.sh
```

**应用可以独立运行**，可将 `dist/macos/FocusCount.app` 复制到“应用程序”目录，也可压缩后发给其他兼容 Mac。接收方无需项目源码、根目录标记或 Xcode。当前脚本生成本机架构，Apple 芯片构建不支持 Intel Mac；要求 macOS 13+。

数据与设置统一保存在当前用户的 `~/Library/Application Support/FocusCount/`，不会打包进应用。启动不再自动导入旧项目数据，旧记录请通过数据管理手动导入。

测试（需要完整 Xcode）：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun swift test --package-path apps/macos
```

修改源码后，先退出旧应用，再重新构建、启动。

本次目录调整保留了原应用于 `dist/legacy/FocusCount.app`（仅作备份，仍使用旧数据路径）；原 `dist/FocusCount.app` 入口已改为指向新版应用的符号链接。日常请使用 `dist/macos/FocusCount.app`。

## 使用

- 点击大号时间，或在空命令输入框中回车：开始、暂停、继续。
- 点击带停止图标的“结束”：填写活动与专注度 S–D 后保存。
- “返回计时”保留进度并恢复为暂停状态。
- 暂停不累计时间，系统熄屏和休眠继续累计，关闭窗口退出。
- 运行中约每 5 秒保存草稿，操作时立即保存，重启后恢复为暂停状态。
- 主界面默认 920×560，可自由缩放（开始页最小 720×440，计时页最小 720×520），支持原生全屏及右上角全屏按钮。暖白／深石墨底色，时分突出、秒稍小，颜色随系统外观变化。
- 默认隐藏历史列表与统计，点击右上角“专注记录”图标打开管理页；左上角“返回计时”或 Esc 可返回并恢复键盘操作。
- 记录页支持日期、科目、专注度筛选；编辑、补记、删除和恢复。
- 记录页右上角“专注分析”打开独立分析窗口；图表与活动分类见下方说明。
- 编辑保留原记录 ID；起止时间与有效时长分别填写，暂停不计时。
- “最近删除”不计入统计，可随时恢复，不自动清空。
- 完成学习与编辑时可选择已有科目；支持深色模式。

## 数据迁移与同步

Mac 的主数据保存于 `~/Library/Application Support/FocusCount/sessions.json`，CSV 自动生成，备份在同目录 `backups/`。数据管理页面提供“打开数据目录”和“打开备份目录”。

Mac 1.20.0 起只读取此数据目录，不再自动恢复旧项目目录或系统 UserDefaults 中的数据。`settings.plist` 保存模式参数、声音选择、颜色、emoji、分类、目标显示偏好、同步开关和分析窗口尺寸；`sounds/` 保存自定义音频。

首次升级时，目录里没有 `settings.plist` 就使用默认设置，不从旧系统偏好迁移；已有记录、目标和声音文件保留。软件会清理旧系统偏好中的应用设置键。

完全退出应用后删除整个 `FocusCount` 目录，再启动就是空记录和默认参数（普通专注；微休息默认随机 3–5 分钟、闭眼 10 秒、专注 90 分钟、休息 20 分钟）。仅删 `sessions.json` 不会重置 `settings.plist` 中的设置。损坏的设置文件会报错并保留原文件，不按“缺失文件”处理。

完整本机备份可在退出后复制整个数据目录；跨设备合并仍使用应用内 JSON 导出/导入。

不同设备通过应用中的 JSON 导出和导入合并交换数据；不要直接覆盖运行中的主文件。移动或更新应用不影响用户数据，发送应用也不会发送个人记录。

数据协议见 [docs/data-format.md](docs/data-format.md)。当前写入版本为 v5，包含可恢复的历史版本；首次读取 v1/v2/v3 数据会保留对应版本备份，旧应用不能继续读写新版数据。为兼容原记录，JSON 日期仍使用自 2001 年起的秒数；CSV 日期为 ISO 8601 UTC。

## 跨设备接续计时（Mac 1.11.0 / iPhone 1.2.0）

1. 在原设备的数据管理中导出 JSON，传到另一台设备。
2. 在接收设备导入文件，预览中可查看导出时间、计时状态、累计时长与活动名称。
3. 勾选“同步计时状态”，再确认合并。未勾选时合并记录和设置，保留本机计时；该选项每次导入默认关闭。

运行中会补上导出到导入之间的时间并继续计时；暂停保持暂停；待保存保持待保存，关闭数据管理后可完成保存。未开始状态也可同步，会清空接收设备当前计时。接收设备的原状态会在替换前备份。

这是手动接续，不是实时联网同步：原设备不会自动停止，建议只在接续设备继续操作。两端分别修改计时时，以本次明确选择导入的文件为准，不相加时长；旧文件可能恢复较早的暂停状态，请核对导出时间。同一次接续计时保留相同 ID，保存后合并不会重复新增；已保存或彻底删除的计时不能再通过旧运行快照接续。

两端需更新到上述版本后重新导出。旧文件仍可合并记录，但无法同步运行状态。Mac 重启仍恢复为暂停，iPhone 保留其运行时间基准；跨设备计时依赖系统时间，请保持设备时钟准确。

## Mac / iPhone 双向合并

Mac 与 iPhone 首页右上角的“数据管理”都支持 JSON 导入、预览、确认合并、导出与历史版本恢复。相同 ID 自动去重，较新修改作为当前版本，其他版本归档保留，不重复计入统计；同时间冲突按固定规则选定，两端结果一致。导入前备份双方数据，默认保留本机计时；勾选“同步计时状态”后接续文件中的计时。

Mac 合并成功后提示“合并完成，新增 X 个（专注记录 X 个，时间标记 X 个，含最近删除）”。这个数量只统计本机此前没有、且本次实际保留下来的记录；更新已有记录、增加历史版本不算新增，被彻底删除规则过滤的记录也不计入。重复导入相同文件会显示“新增 0 个”。

两端都更新后再交换 v5 文件。请选择“导入并合并”，不要直接覆盖正在运行的应用数据文件。此功能不提供后台云同步；完整规则见数据协议。

“最近删除”支持单条彻底删除与清空全部（包含筛选外记录），确认后移除记录及其历史版本，仅保留防止旧文件导入复活的 ID。已有独立备份不受影响。

Mac 开始计时后可点击底部叉号按钮取消本次计时，确认后归零，不生成学习记录；休眠前若手动暂停，唤醒后仍保持暂停。退出应用后重新打开仍按已保存草稿恢复为暂停。

## Mac 指令与时间标记

- 点击结束按钮保存专注；`!stop` 现在只标记 stop，不再结束计时。
- `!文字`：记录标记及当下时间，英文统一小写，如 `!sex` → sex、`!Sad` → sad；支持中文和词组，不改变当前计时。
- 开始页可直接在活动输入栏输入 `!文字` 并回车添加标记，不启动计时。计时页点击“标记”展开输入框；成功标记后自动收起，Esc 可收起。空标记不保存。未编辑标记时可通过回车开始、暂停或继续。

时间标记位于“专注记录 → 时间标记”，支持删除、恢复及彻底删除，不参与专注时长、次数或图表统计；随 JSON 自动去重合并。CSV 仍只导出时长记录，完整备份请使用 JSON。iPhone 的记录页提供时间标记管理，支持相同的 `!文字` 语法，点击“结束”保存专注记录。两端应更新后交换 v5 数据。

Mac 1.6.1：精简开始页，移除顶部标语与底部操作栏；专注记录、数据管理和全屏图标统一排列于右上角，全屏位于最右。计时页操作依次为“暂停／继续、标记、取消、结束”，取消仍保留确认。数据格式仍为 v5，新自定义标记可被 iPhone 显示和合并。

Mac 1.6.3：暂停页移除中央继续按钮，恢复琥珀色静止波纹；底部继续、点击时间和回车仍可恢复计时。开始页加大主文案、辅助文字和按钮字号，重新调整分组间距，默认窗口为 920×560；系统已记住的用户窗口尺寸仍会保留。

## Mac 时间标记（1.11.0）

入口：右上角“专注记录” → “时间标记”。页面为可视化、时间轴、最近删除。iPhone 1.1.0 已同步核心可视化能力，并适配手机交互。

时间标记使用独立的 Mac 窗口，可拖动标题栏移动，支持最小化、全屏和拖动边缘调整大小，并记住窗口位置与尺寸。默认内容区为 1440 × 810（16:9）；升级后首次使用新的默认尺寸，此后保存用户调整。最小内容尺寸为 1000 × 700；图表与日期导航随可用空间扩展，侧栏宽度保持不变。“返回记录”关闭此窗口，原记录页面保留。

- 可视化默认进入「频率总览」：每种标记独占一行，气泡表示对应日期内的次数；空白日期保留。所有行共享面积比例，极端值达到尺寸上限后显示数字，悬停或点击均可查看精确次数。空间足够时气泡显示设置的 emoji，密集视图使用颜色，行首始终保留标记名称和 emoji。
- 本周默认完整展示周一至周日，未来日期明确标注；30 天完整展示每天；全部从最早未删除标记至今天。自动粒度在 45 天以内按天、280 天以内按周，更长按月；也可以手动选天、周、月。周以周一开始。未完整的周、月带底线提示，详情显示覆盖天数。

Mac 1.18.0：模式设置顶部横向选择编辑对象，不改变当前运行模式；右上角设置的「提示音」分栏提供六种内置声音，支持导入与重命名自定义音频（不超过 50 MB）。微休息可分别选择开始休息与开始专注的提示音并试听，下一轮生效。自定义文件存入数据目录 `sounds/`，暂不随记录交换；缺失音频会回退默认声音并提示。

### 完整手动同步（Mac 1.19.0 / iPhone 1.5.0）

两端更新后重新导出 JSON，即可同步记录、历史版本、最近删除和彻底删除标记、目标日期、目标隐藏状态与显示方式、标记 emoji 与颜色、活动分类与颜色、专注模式参数、声音选择、自定义音频与名称。窗口位置、系统通知权限和签名属于设备环境，不参与交换。勾选「同步计时状态」还会接续微休息的当前阶段和剩余时间，休息仍不计入有效时长；原设备不会自动停止。

设置按条目保存修改时间，互补合并，同一条目采用较新修改，时间相同使用固定顺序决胜。清除 emoji、删除分类会保留删除标记，导入旧文件不会复活。升级前没有修改时间的设置按固定规则合并；之后手动调整会获得新的修改时间。自定义音频随 JSON 内嵌传输，文件可能明显变大；导入文件上限 512 MB，单个音频上限 50 MB。旧格式不包含的新字段不会清空本机设置。以上规则替代旧版本说明中的「设置仅本机保存」。

iPhone 左上角仅保留 🧠，Today’s focus 恢复标题在上、时长在下的排版，保留深浅层级。


### 提示音本机设置（Mac 1.19.1 / iPhone 1.5.1）

模式同步只包含五个时间数值：间隔下限、间隔上限、微休息秒数、每轮分钟数、长休息分钟数。不再同步默认模式选择、声音选择、音量或自定义音频。导入旧文件同样忽略其中的声音配置和音频附件，已有本机音频不删除；接续计时时使用接收设备的声音设置。emoji、颜色、分类、目标设置和记录仍照常合并。本节替代 1.19.0 / 1.5.0 的声音同步说明。

iPhone 模式参数页将试听改为独立表单行与独立按钮，避免点击时打开声音选择菜单。


### 导入历史与可选同步（Mac 1.19.2 / iPhone 1.5.2）

数据管理的历史页面现在同时显示历次导入前备份、导入文件及单条记录旧修改。旧备份直接从原目录发现，点击“查看并合并”重新进入预览，不执行整库回退，不撤销永久删除。

预览仅列新增、更新和删除等变化，并显示文件导出时间、来源设备。交换容器增加可选 `source`（`exportedAt`、`device`、`platform`）；旧文件缺失设备信息时显示未知，不猜测来源。

导入新增两个默认开启的独立开关：“同步自定义提示音与声音设置”“同步模式数值参数”。计时同步仍默认关闭。导出重新包含 `sounds` 附件，以及独立 `soundPreferences`（`restSound`、`focusSound`、`volume`）；声音设置采用所选文件值，附件按 ID 和修改时间合并。模式数值仍通过 `sharedSettings.entries.mode` 合并，只包含五个时间数值，不包含默认模式选择。关闭相应开关不会写入该设置的远端修订。旧文件缺少字段时保留本机设置。

声音先验证后批量写入，记录写入失败时回滚声音文件与索引。同步计时但关闭参数同步时，仅接续本轮阶段节奏，下轮保留本机参数。此节替代上一版“不传输任何声音”的规则；完整交换需更新两端并重新导出。


### 历史删除与固定导出时间（Mac 1.19.3 / iPhone 1.5.3）

历史页面支持删除单份导入备份和单条记录旧版本，均有确认提示，不影响当前记录。备份删除仅作用于本机文件；记录旧版本的删除通过 `purgedHistoryIDs` 同步，避免旧文件重新带回该版本。

每份导出 JSON 固定写入 `source.exportedAt`，另附人可读的 `source.exportedAtISO8601`。预览读取前者，不依据文件修改时间；修改其他内容或重命名文件不会改变所显示的导出时间。缺少该字段的旧文件显示未知。时间字段可被人工编辑，因此它记录导出时间，不提供防篡改认证。


### 删除全部历史版本（Mac 1.19.4 / iPhone 1.5.4）

两端历史页面新增“删除全部历史版本”，确认时列出导入备份和记录旧版本数量。两端 Store 的 `deleteAllHistory()` 先原子保存所有记录的旧版本删除标记（Core `RecordExchange.deletingAllVersions(from:)`），再删除本机导入备份；保留当前记录、最近删除记录、时间标记及计时。数据库保存失败时不删除备份；文件清理失败会显示错误并刷新剩余备份，允许重试。不会为本次清理再生成一份历史备份。记录旧版本的删除标记参与后续同步，其他设备的本机备份需在对应设备清理。


### 本机同步偏好（Mac 1.19.5 / iPhone 1.5.5）

“同步自定义提示音与声音设置”和“同步模式数值参数”移至设置中的“同步设置”，默认关闭，按设备持久记忆。导入预览不再显示这两个开关，每次直接使用本机选择；计时状态仍在预览中临时选择，默认关闭。

共享常量 `SyncPreferences.soundsKey/parametersKey` 位于 Core `SharedPreferences.swift`；两端设置页和交换页通过 `@AppStorage` 使用同一组本机键。导入时仍向 Store 显式传入两个选择，预览变化也按相同选择计算。这两个偏好不进入 `SharedPreferences` 交换内容，导入其他设备的数据不会重置它们。导出内容不受本机导入偏好影响。此规则替代上一版“每次导入默认开启”的交互。


### 聚合标记数量（Mac 1.19.6 / iPhone 1.5.6）

两端频率总览的聚合次数达到 4 次即显示下方小数字，不再仅在尺寸封顶时显示。Mac 时间分布也采用相同的 `MarkerCountBadge`（`MarkerFrequencyOverview.swift`，9pt 数字、浅色胶囊背景），布局为数字预留避让空间。无 emoji 的彩色点同样标注。Mac 时间分布的 2 次聚合直径由 44 降至 34，3 次仍约 48，其余放大规则保留。频率总览的窄日期列按数字宽度保留最小间距，必要时横向滚动。
